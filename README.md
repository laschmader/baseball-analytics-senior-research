# baseball-analytics-senior-research


The goal of this Senior Research project was to examine the potential impact of the Automatic Ball and Strike System (ABS) on professional baseball hitters in terms of strikeout rate, walk rate, swinging strike rate, and number of balls, strikes, and pitches seen throughout a season. Data collected from FanGraphs included 2,068 player-season observations representing 1,135 distinct Triple-A players with at least 200 plate appearances from 2019 to 2025. Since ABS was fully implemented in Triple-A beginning in 2023, the dataset was separated into pre-ABS and ABS periods. Using hypothesis tests and Fixed Effects Regression models (OLS and Poisson), offensive performance metrics were compared before and after implementation. Results showed that several statistics experienced significant short-term changes following the introduction of ABS, particularly during 2023, before gradually returning toward pre-ABS levels over time. These findings suggest that players adapted to the new strike zone environment and that similar adjustment patterns could occur if ABS is implemented in Major League Baseball.
